1. 先读取官方元数据、许可、文件清单，取得明确文件字节数与校验信息。
2. 许可确认后选择最小音频+对应标注及可穿戴样本，逐列检查标签和时间轴。
3. 未提供官方 SHA-256 时仅记录本地计算值，明确不证明官方来源完整性。
4. 超过 500 MB 或全量数据必须单独获得用户明确确认；BIDSleep 默认不下载。
5. 若声音主候选无法取得许可或时间标签，提交证据并比较备用方案，未经讨论不悄悄改变研究任务。
