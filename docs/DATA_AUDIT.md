## 获取计划

先核实官方许可、原始下载入口、精确字节与校验值；再以最小样本检查字段和时间。对来源含糊、官方校验不匹配、时间对齐冲突的文件拒绝进入训练。

- 主声音：保持冻结，先调查同步问题；声音基线改用已通过最小审计的PSG-Audio继续开发。当前只获准一个EDF分片，后续不得自动下载其余分片。
- 可穿戴：已选一人的三文件校验与覆盖审计通过。一个人只用于解析，正式训练前需另列多受试者获取计划。
- 全量或超过500MB的下载必须等待用户明确确认；应用启动不下载数据。BIDSleep默认不下载。
- 样本工具默认dry-run，明确--execute才获取一个已审计文件；本地摘要与官方摘要分开报告。原始音频、信号、私有标签和权重不进Git。

## Phase 0 退出条件

两条路线均需有许可与引用、实际文件/标签粒度/时间戳、精确大小和下载/完整性策略的证据。主声音时间冲突已记录并由备用PSG-Audio样本提供可行路径；可穿戴三文件与时间覆盖已实测。当前通过的是最小数据可行性，不能用它声称模型/全库验收完成。
