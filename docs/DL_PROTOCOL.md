# 轻量神经模型试点协议 v1

2026-10-25，正式训练前固定。用户已明确恢复GPU可用窗口与满功率供电；本轮使用单GPU进程、CPU最多2线程、准备worker1，不更改系统电源或其他项目。

数据仍为已获授权并验证的PSG-Audio十人各第二小时与SleepAccel三人，不新增受试者或下载完整数据。沿用旧受试者划分和标签策略，不随机切分重叠窗口/epoch。数据、派生张量和权重不进入Git。

- 音频：Mic原始48kHz，重采样16kHz，10秒窗/5秒步长。400样本Hann帧、160步长、512FFT、32个HTK mel带，功率地板1e-12取自然对数。将实际STFT帧的log-power按时间分成100个非空连续组取均值，得到32×100；不能用旧67维摘要伪造声谱图。每人保留全部719窗，只有原监督mask为真的窗口参与训练和窗口分类评分；验证/测试连续事件使用全部窗口。
- 可穿戴：30秒epoch，每秒HR均值、加速度XYZ均值及模长标准差，共5×30；2×30独立观测mask。缺失保持NaN直到标准化，逐项相同重复块显式折叠，不插值、不修补其他倒序。对应经典v2标签、身份和时间逐项核对。
- 标准化：在全部已评分训练行的观测值上，按输入通道拟合总体均值/标准差；常量标准差用1。音频按32个mel带，wearable按所选值通道。验证/测试只transform；wearable缺失标准化后为0，并拼接独立mask。HR、accel、融合三个版本分别只用其自身通道拟合。
- 音频CNN：Conv2d 1→16→32→64，3×3/pad1，GroupNorm/ReLU；前两层后2倍池化，最后全局平均池化，Dropout0.1，Linear64→2。无BatchNorm、预训练权重或大模型。
- 可穿戴CNN：Conv1d C→32（核5/pad2）→64（核3/pad1），GroupNorm/ReLU；首层后2倍池化，最后全局平均池化，Dropout0.1，Linear64→5。输入C=2（HR+mask）、5（4种accel+mask）、7（融合+2mask）。
- 优化：seed42；AdamW lr0.001、weight_decay0.0001；batch64；最多20epoch，patience5；训练类别权重N/(K×训练类数量)，梯度范数裁剪5。固定FP32，不启用AMP/TF32。训练顺序固定种子打乱，CPU两线程、DataLoader不启动子进程。
- 选择：每epoch仅看验证集Macro-F1，严格提高才更新检查点，平分保留最早。达到patience停止；测试集只在最终选定检查点上评价。不按本轮测试结果搜索参数/阈值，不承诺CNN优于RF。
- 核验：先运行最多5个训练batch的smoke，只评价validation、不读测试指标。测量耗时与峰值显存后报告正式四个训练的预算。正式保存CPU state_dict，以weights_only=True加载，要求同设备、同batch下概率逐项相同。CPU路径必须可运行。
- 指标：同既有固定类别顺序，Macro-F1/平衡准确率/每类P-R-F1/混淆矩阵，音频另报AP。音频连续事件严格沿用EVENT_PROTOCOL.md，无新阈值选择。记录每epoch验证分数、类别数量/权重、标准化参数、依赖、源代码/输入/权重摘要、耗时和显存。

软件环境选择PyTorch2.9.1 CUDA12.8官方Windows CPython3.12轮子，不宣称最新版本。本机已有2,862,033,275字节pip缓存，与官方索引SHA256完全一致后复用；另外8个小依赖共9,556,742字节与官方PyPI摘要匹配。项目独立venv，未修改全局或其他项目。候选CPU2.14轮子之前超时且从未安装，本轮不再尝试该版本。GPU包来源/摘要见DL_WHEELS.json，实际CUDA矩阵运算与sm_120支持已验证。

正式批次前实际smoke：音频5batch+validation约14.5秒，峰值张量显存141,020,672字节；wearable约4.1秒、70,169,600字节。保存加载概率逐项一致，没有测试分数。计划四个模型顺序运行、最多20epoch/模型，预计总计15分钟以内；这是预算而非保证，持续观察实际handle与每epoch进度，若出现异常耗时或资源争用先报告并停止增加任务。

每个可穿戴集合仅一人、音频验证/测试各两人、专业麦克风与手机域不同，当前只能做流程试点和负面结果分析。个人手表无PSG金标准，个人录音与室友资料没有因此获得采集或公开授权。
