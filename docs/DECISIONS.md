## 优先改进：数据决定任务定义

声音数据的 PSG 呼吸事件可支持研究音频与事件的关系，但不自动提供逐声鼾声标签。先审核 JSON 与录音时间轴，明确预测目标、背景窗定义和事件匹配容差，再冻结基线任务。验收：实际样本字段、标签枚举、跨午夜/录音偏移检查与受试者划分报告。

SleepAccel 与 BIDSleep 使用不同标签编码与时间基准，分别实现适配器并转换为内部语义类别，禁止共享未经验证的数字标签映射。先完成 SleepAccel；BIDSleep 保留为可选扩展。

## 2026-10-24：主声音时间冲突与数据路线

两个实际JSON、阶段CSV及4份WAV头显示事件跨度超过对应音频声明时长，详细数值与证据见SOUND_AUDIT.md。主候选先冻结事件训练；不按比例缩放或擅自裁去越界标签。优先推进原任务书备用PSG-Audio的文件/标注/时间对齐审计，只有通过后才确定训练数据。备用数据全量918GB，当前不下载全量。研究目标仍为声音事件与鲁棒性，尚未降级标签粒度。

通过官方接口取得主声音Data/01至50的全部380个数据文件元信息，实际只48个目录含phone文件，11和17缺phone；原先50人均有手机的概览不能直接视为实际文件完整性。该缺失应计入后续纳入/排除报告。
