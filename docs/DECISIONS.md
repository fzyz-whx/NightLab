## 优先改进：数据决定任务定义

声音数据的 PSG 呼吸事件可支持研究音频与事件的关系，但不自动提供逐声鼾声标签。先审核 JSON 与录音时间轴，明确预测目标、背景窗定义和事件匹配容差，再冻结基线任务。验收：实际样本字段、标签枚举、跨午夜/录音偏移检查与受试者划分报告。

SleepAccel 与 BIDSleep 使用不同标签编码与时间基准，分别实现适配器并转换为内部语义类别，禁止共享未经验证的数字标签映射。先完成 SleepAccel；BIDSleep 保留为可选扩展。
