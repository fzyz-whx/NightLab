# 连续音频事件评价协议 v1

2026-10-24，在运行真实事件指标前固定。对应 `audio/events.py` 的手算测试已通过；本次将既有冻结的多数类/RF窗口模型接入连续推理，不重训、不据测试分数选择阈值。

- 数据：PSG-Audio V3 已授权十人试点中的固定验证两人、测试两人，各第二小时。保留原先受试者划分；不把两集合合并选择模型。
- 输入：每小时全部719个10秒窗口、5秒步长、Mic通道、原67维特征。复用校验过的监督特征，只补算此前因边界不明确被排除的窗口。补算窗口仍不取得监督标签，不加入旧模型训练或窗口分类分数。
- 一致性：重新校验原始文件官方MD5、本地SHA256、旧特征/时间轴SHA256与特征源码；重新核查EDF/RML时钟、全部窗口标签与几何；每条录音重算第一个已存窗口，要求特征逐项完全一致。缓存以版本、输入、源码及产物摘要识别，拒绝静默覆盖。
- 解码：每5秒一个半开区间bin（最后可短于5秒）。取覆盖bin中心的全部窗口正类概率均值，`>=0.5`为阳性，相邻阳性bin合并为预测区间。每个bin必须有真实窗口预测；不能将无标签或缺失窗口填零。
- 参考：RML四类 `Hypopnea/ObstructiveApnea/CentralApnea/MixedApnea`，保留逐事件间隔和类别，不合并相邻参考。裁剪至观测分片后换算为相对秒；只接触边界、零交集事件不纳入。越过任一分片边界的事件标记censored，参与检测但不进入起止误差。
- 匹配：预测与参考一对一，IoU至少0.5，先最大化匹配数量，再最大化总IoU。不同受试者/录音不跨边界匹配。报告TP/FP/FN、Precision/Recall/F1、FP/观测小时；分母包括整段观测，不限于明确监督窗口。
- 汇总：分别报告validation/test的每条录音结果以及微平均；先相加TP/FP/FN和观测秒数再算率，不对单人率直接取均值。没有预测时Precision为null；没有参考时Recall为null；两边皆空F1为null。null表示未定义，不伪造为满分。
- 定位：只在成功匹配且未截断的参考上计算预测减参考的起止误差、平均绝对误差；汇总以匹配数加权。它不描述漏检的定位能力，必须同时报告检测召回。
- 保存：本地runs保留每窗概率、每bin概率、预测/参考间隔与匹配；公共报告仅保留匿名每人计数、聚合指标、参数与来源摘要，不发布原录音、原始参考时间轴、权重或患者头字段。

这是参考生理呼吸事件的音频模型评价，不是听音确认的鼾声检测，也不诊断疾病。每集合两人、各仅一小时、专业麦克风与手机域差异仍是限制。既有测试集已用于先前基线报告，后续模型比较须保留这次冻结协议和负面结果，不能反复依此测试集调参。
