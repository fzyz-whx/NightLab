# SleepAccel重复块处理与输入质量

更新：2026-10-24。规则是sleepaccel-classic-v2的显式配置，原始文件不修改。

## 实测问题

受试者1066528的心率文件已匹配PhysioNet1.0.0官方SHA256（31533209b9a515c331eb41800f676885e652ebda9077794d44ccbfb90342c3e7），所以这不是本机续传损坏。
原始16617行在两个位置出现严格时间回退。按回退边界分成三段，每段5539行；三段的全部时间和值逐项完全相同。加速度1281000行没有回退。

最初严格解析器拒绝此记录，corpus.complete=false，训练入口拒绝不完整人群。没有将失败悄悄当作成功。

## 显式处理策略

默认repeated_block_policy=reject仍拒绝任何非严格递增时间。试点manifest明确设为collapse_identical：只允许由严格回退分开的完整块长度相同且所有时间/值完全相等，保留第一块；有相同时间点、非完全相同的块或其他回退仍报错。标签不适用该处理。

这是删除逐项重复副本，不排序、不平均冲突值、不插值、不改标签。metadata记录原始/有效行数、重复次数、折叠样本数。该记录心率保留5539行，折叠11078个逐项重复样本。

v1严格输入的失败被保留；v2写新特征路径并保留原始参考文件。变更依据输入完整性与时间结构，未按模型指标选择修复方法。
