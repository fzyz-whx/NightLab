# NightLab 研究方案与进入训练的门槛

状态：预注册草案，2026-10-23。没有实测结果。实际数据审计可能要求修订，修订需保留原因。

## 两条独立路线

声音：以公开参考标注支持的粒度预测呼吸相关事件，研究手机录音的噪声鲁棒性。不能将 PSG 呼吸暂停等同于可听见鼾声，也不能从病例数据推断一般人群筛查能力。
可穿戴：SleepAccel 心率与加速度预测 PSG 睡眠阶段；个人手表数据没有参考标签，只能演示和探索。两个来源受试者不同，不能拼接训练融合模型。

## Phase 0 的退出条件

- 固定来源、版本、数据许可与引用；精确下载地址和选定文件的大小/完整性策略有证据。
- 至少核实一组音频与标注、一组心率/加速度/阶段文件；解析字段、单位、缺失值、时间零点和标签枚举来自实际内容。
- 音频起点、跨午夜及 PSG 偏移须有证据，不能依赖文件下载后的修改时间。
- 样本不足时不得运行“泛化评估”。下载计划明确样本与全量之别；大于500 MB和全量单独确认。

## 划分与泄漏控制

先冻结受试者列表与随机种子（候选42），再生成窗口；每人全部夜晚同组。生成 split manifest 并检查交集为空。小规模调通样本只用于解析测试，不进入正式比较。
数据规模确认后确定 subject-wise train/validation/test 比例或 GroupKFold；类别分布、受试者数一并报告。若某阶段在测试集缺失，报告支持数和指标限制，不隐去该类别。
所有缩放器、填补器和特征选择仅拟合训练集；阈值/超参数在验证集选择，最终测试集只用于冻结后的评价。

## 声音实验的最小可解释对照

先实现手工特征+Random Forest，之后实现 log-mel CNN。比较原始音频、传统滤波、噪声增强训练。固定划分、窗长与评价集，分别改变处理方式，避免同时改变模型和数据导致无法归因。
事件标注可用时：预先规定窗口与事件的重叠规则、事件合并/匹配规则及容差；容差根据标注分辨率与同步误差确定并记录，不在测试集上挑选。报告 PR-AUC、Macro-F1、事件 F1、每小时误报及起止误差；临床事件预测与可听声音识别分开命名。
噪声实验在划分后混合，固定 -5/0/5/10 dB；审核噪声来源与同意范围，控制削波，保存原始目标片段与噪声素材关联。无干净配对参考不报告监督去噪性能。

## 可穿戴对照

多数类基线、Random Forest、轻量1D-CNN或GRU；分别用心率、加速度、两者。以参考阶段 epoch 对齐，检查时间覆盖率，避免插值跨越过长缺口。缺口阈值须由训练分布与数据采样机制确定。
主指标 Macro-F1、balanced accuracy；附各类支持数、F1和混淆矩阵。Unknown 保留为明确无效状态，不强行转换为清醒；不同数据集数字映射由各自适配器定义。

## 报告和不确定性

每次实验记录数据版本、文件摘要、受试者划分、种子、参数、依赖版本、运行时间与模型版本。区间估计以受试者为重采样单位，不能把高度相关的相邻窗口当作独立样本。小样本时明确区间不稳定。
汇报失败案例、负面结果、设备差异与人群偏差；没有临床前瞻性验证，不作医疗准确率或诊断承诺。

## 2026-10-24：试点训练协议冻结

声音采用10人各第二小时，先以seed42/PCG64按受试者6/2/2，再生成10秒窗/5秒步长，目标事件并集覆盖至少0.5为正、零呼吸事件重叠为背景、其他排除。可穿戴先三人1/1/1试点，全部输入处理/重复块规则显式记录。RF200树、深度12、叶最少3、balanced_subsample、CPU单任务，缺失统计仅从训练数据拟合。

PSG中位时序和用户标签并非同一标签语义；实际目标叫reference_respiratory_event而不是“鼾声真值”。现有窗口结果与事件级检测分开，后者仍需全窗口推理与匹配。实际结果和局限见EXPERIMENTS.md，保留首轮冻结结果；后续不得依据已看过的测试分数反复挑选参数。
