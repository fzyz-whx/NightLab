# 隐私与数据流

更新：2026-10-26。NightLab默认仅在本机运行，不诊断或提供医疗建议。

录音导入前必须确认对所有可能被录到者具有使用权。有人拒绝则不得采集；含可识别谈话的声音默认不作为增强素材。本次仅用公开数据和明确标记的合成测试，没有采集室友声音或取得真人手表数据。

## 应用存储与网络

默认服务绑定127.0.0.1:8766；React构建与API由同一个本地服务提供，不加载远程字体/图表CDN。FastAPI的tracing、metrics、logs、operation_spans、auto_configure明确关闭；无分析SDK或云上传功能。安装依赖或显式运行数据获取脚本会联网，打开应用、导入和推理不自动下载数据/权重。

个人数据默认保存在忽略目录private/app，也可用NIGHTLAB_DATA_DIR指定本机位置。records/<UUID>/audio.wav保存原始音频；nightlab.sqlite3保存记录元信息、音频SHA256/格式、规范化可穿戴附件、用户/模型标记与任务。上传暂存在staging，完整读取校验后才发布；格式错误/中断应清理暂存。原始厂商CSV/JSON不另存副本，数据库保存实际导入的规范化观察和summary；缺口保留，不伪造设备值。谱图/波形按需计算响应，不创建额外永久图片缓存。

变更API要求本地客户端自定义header，开发CORS仅允许localhost/127.0.0.1:5178；Host检查防止任意主机名访问。它是单用户本机服务，没有账号或远程多用户访问控制；不要擅自改为公网监听。其他有本机文件访问权限的程序仍可能读取文件，存储未额外加密。

## 确认删除与取消

删除对话框列明音频、附件、衍生结果和标记；取消对话框保留记录。活动任务须先请求取消、等到终态，后端也阻止竞态删除。确认后检查路径和链接，再删除该UUID目录及SQLite记录；外键级联移除events/wearable/jobs。API只有实际删除后才返回deleted:true，前端随后释放播放器。

文件删除失败时不提前删数据库索引，允许用户关闭文件占用后重试。文件系统与SQLite不是一个共同事务：极少见的文件已移除但数据库提交失败，可能留下可再次删除的索引。删除不等于磁盘安全擦除，已导出的CSV、操作系统备份、回收或存储介质残留不会由应用自动删除。

任务使用单worker、合作取消；已取消不发布部分模型事件，保留旧结果和用户标记。服务重启将遗留queued/running任务标为失败并允许重试，不声称自动续训或恢复尚未完成的分析。当前仅支持单服务进程，启动脚本拒绝已有端口。

## 研究数据与公共仓库

公开原始EDF/RML/声音/可穿戴、processed、models、runs、private、数据库和日志被.gitignore排除。RML/EDF可能有身份/就诊字段；公共报告仅聚合计数和必要匿名来源，不复制原始Patient/ContactInfo、就诊时间、逐行生理信号或逐窗概率。归档响应headers可能含站点cookie，只留忽略目录。

公共截图仅为本地生成的合成Demo或公开聚合研究图，始终说明synthetic。公共Git提交只有自写代码/文档、依赖锁、官方清单及非敏感聚合结果。SleepAccel31授权与93成员验收已完成；steps等未提取。数据和第三方依赖保持各自许可，MIT仅覆盖本项目自写部分，见DATASETS.md。

个人录音/手表没有PSG真值时只用于探索、显示和人工复核，不计算个人准确率、健康评分或医学结论。公开数据上的研究指标与本机软件测试也不等于真实设备或临床验收。
