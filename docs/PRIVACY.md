# 隐私与数据流

更新：2026-10-26。当前含公开数据审计/获取、传统与轻量神经训练、派生缓存和实验报告，尚无个人数据导入或删除界面。

原始公开音频/EDF/RML/可穿戴信号仅保存在本地data/raw，.gitignore排除；processed、models、runs及私有日志也排除。GitHub只提交自写工具、测试、官方来源清单、摘要和不含个人字段的汇总审计。默认没有云上传或遥测。

RML/EDF可能包含身份字段模板及敏感健康信息。检查工具只输出必要的通道元信息、相对时间、类别计数和信号汇总，不输出Patient/ContactInfo内容或绝对就诊时间；下载的原文件、元数据头及作者代码不入库。

当前网络行为仅为明确执行的数据获取，先展示许可、官方原始来源、精确大小、校验方式与范围。sample默认dry-run；大文件download必须有用户授权并传--confirm-large-download，限明确选中的一个文件。不在启动时下载。

SleepAccel31人归档已取得针对576850847字节的明确授权。归档传输完成与逐成员CRC/官方SHA验收是两个状态，partial和未验收内容不作为正式数据。续传的headers可能含站点负载均衡cookie，只留忽略目录，不复制到公共日志/报告。当前合成白噪声/工频不是室友录音，没有采集新的真人声音。

后续个人音频采集必须取得所有可能被录到者的知情同意，拒绝者不得被录制。含谈话的片段默认不作为噪声增强素材。个人手表没有PSG参考，不用于正式准确率报告。

当前没有应用级删除功能；文件仍由用户在本地管理。后续需实现列出关联记录、确认后删除原始文件/衍生结果/数据库索引，测试取消与确认路径。不能因底层文件删除成功就宣称关联数据已全部清除。

本软件用于研究，不诊断或提供医疗建议。公开数据可访问、摘要匹配或时间结构一致均不代表临床有效性。
