# 下一阶段：本地研究工作台实现契约

2026-10-26，Phase2试点通过后进入实现。本文件是设计约束，不表示已有API/UI。目标仍是原任务书的三页本地工具，不能将CLI阶段当作最终软件交付。

## 入口、依赖与存储

- FastAPI/Python3.12、React/TypeScript/Vite、SQLite，Windows PowerShell启动；只监听loopback，不强制Docker/WSL。当前实查Node24.22.1/npm11.19.1可用；项目venv尚无FastAPI/uvicorn/soundfile/httpx。依赖先解析预算、核官方来源与hash后锁定，局部安装，不升级/修复其他项目。
- 后端优先8766、前端5178，当前未监听，启动时重新核查/可由环境覆盖；冲突不杀其他进程。后台启动用隐藏窗口/工具session并记录PID，验证后复用自己的服务。
- 个人记录使用独立本地private目录与SQLite索引，不混入公开dataset原目录。文件名由UUID生成；用户文件名仅作显示。导入先暂存、校验、原子发布，失败清理自己的暂存与数据库关系。
- 无启动自动下载、云上传、遥测或模型API。模型只使用本机已核验的自有checkpoint/收据，拒绝未知joblib；默认CPU。CNN依赖可选，缺模型时仍能导入/浏览信号，显示真实不可用状态。

## 普通流程与页面

1. 夜间记录（默认）：导入WAV，可选心率/阶段/加速度CSV或JSON；显示录音波形、实际可用时序和模型/用户标记。空、加载、错误、缺失状态完整；无健康评分。
2. 事件检查：播放器、波形、局部声谱图与时间轴联动，点击标记定位局部区间，显示来源、模型得分/版本；用户标注与模型预测区别，非公开参考数据不得叫“真实事件”。导出事件CSV保留来源。
3. 实验比较（高级）：读取已登记真实JSON/图表，比较传统/CNN/滤波/噪声增强/可穿戴消融。公开数据版本/匿名人数/分组/种子/超参按需展开；不以合成Demo冒充研究结果，不展示未实现预设的死按钮。

视觉中文为主，克制中性色与统一间距/单位，普通流程不堆训练参数。只有当用户决策需要时才显示实现细节。导入同意确认说明对所有可能被录到的人有使用权；工具不自动录音。

## 时间与格式契约

- WAV校验真实容器/采样率/通道/帧数/大小/时长，分块读，不整晚载入内存。具体接受格式和大小上限必须文档化；截断、非有限或不支持格式明确报错，不靠扩展名判定成功。
- 通用CSV/JSON提供下载模板。时间支持明确的相对秒或带时区ISO/明确单位的epoch；不猜毫秒/秒或设备时钟同步，不偷偷排序/插值修复异常时间。
- HR、阶段、加速度的单位与标签映射明确；保留缺失/未知和原始来源。缺口显示断线/空段，训练填补值不能显示成实测曲线。仅夜间汇总则展示汇总，不生成假时序。
- 个人记录无PSG金标准，只探索，不产生正式准确率。声音与可穿戴并列不称为联合融合模型。厂商专有接口/真实设备导出未取得时不阻塞通用导入。

## API与工作流分层

分api、schemas、storage、services，业务不全塞一文件；复用旧audio/deep/wearable函数，避免修改已冻结特征定义导致历史缓存失效。

预期API包括health、records列表/导入/详情、受控audio Range流、分块波形/局部声谱图、可选时序附件、用户标记、事件CSV、demo生成、分析jobs状态/取消，以及experiments真实报告。客户端只传UUID/枚举，不传任意服务器文件路径。

长任务单worker/数值两线程，进度由真实已完成窗口计数驱动，支持安全取消和失败状态。项目内队列不冒充跨项目GPU排队。删除必须确认，协调活动任务，删除原始/附件/衍生物与DB关联；测试应检查物理路径和索引，不能只拿HTTP200当删除完毕。

## 端到端验收边界

- 合成Demo由确定性脚本生成、始终标记synthetic/demo；示例标记不是PSG参考。研究指标继续来自已冻结真实实验。
- 验证真实本地API→文件/SQLite→特征/自有模型→结果→UI路径；覆盖坏音频/缺列/未知标签/坏时间/错误与取消/缺失/删除确认；前端typecheck/lint/build。
- 用实际浏览器验证导入、时间轴、事件、CSV、状态和删除，再保存真实截图。用户睡觉期间使用隐藏/headless且静音浏览器，不自动外放声音；播放器currentTime前进只证明媒体流程，不宣称用户听到了。
- 未完成或未取得的真实个人设备联调如实列出，不能把合成或组件测试当设备/医学验证。软件许可、引用、README与中文讲解稿在最终交付阶段补齐，整体goal届时再逐项审计。
