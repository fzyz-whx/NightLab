# 公开数据主项目增量验收

2026-10-26，按用户最新范围执行：公开数据即为完整主项目，本人采集/Android 是可选 DLC。当前目标与可复现操作见 [CORE_DELIVERY.md](CORE_DELIVERY.md)。

## 实际完成的闭环

- 复用已经获批、校验与准备的 PSG-Audio 十人，固定验证集两位受试者各自所在第二小时 EDF 的前 120 秒；不根据预测表现选片段。没有下载新文件，也没有 GPU 训练。
- 新增公开样例 API 与首页入口；导入前用既有 `record_context` 校验官方原始摘要、当前准备产物与源码收据及 EDF/RML 时间对应，然后有界读取 `Mic`，以 float32 WAV 保留 ADC 比例，副本落在忽略目录。
- RML 中四种目标呼吸参考裁剪为独立 `reference` 来源；参考、预测、用户、合成来源分别显示并写入 CSV。参考不能被当作用户标记删除，模型重跑也保留参考。没有经过核验的源时区，绝对时间留空。
- 使用新 `app_audio_rf` 入口在 CPU 真正训练 `public-core-audio-rf-v1`，200 树、单 worker、数值线程最多二；产生本次模型/metrics/源码/依赖绑定的私有收据。实际权重 SHA256 为 `a20408410200c503928ba3318d2cdada4a4257926e48e39ba4cce90c15865199`，与历史同配置 RF 相同；本轮不是另一台机器全研究重建。
- 显式登记本次经典实验快照，实验页实际显示八个内置报告和一个本地复现。聚合指标、混淆矩阵、逐类统计与真实新 metrics 一致；保留缺类/指标定义说明，坏本地登记不会阻断内置报告。
- 主线程用实际内嵌浏览器打开两个公开样例、选中新 RF、完成任务并打开新登记报告。第一个固定片段没有目标参考，如实为零；第二个有两条 PSG 参考，模型完成 23/23 窗口并产生两个候选区间。这里不重新评价、挑选阈值或声称识别可靠。
- 实际 HTTP 导出的 CSV 包含两条参考与两条预测；确认删除验收副本后 records/events/wearable/jobs 四张表均为零，记录文件夹为空；原始 EDF/RML 再哈希保持一致。

浏览器截图保留在本机 `private/public-core-acceptance-evidence`，不将原始波形/参考区间图复制进公共仓库。公开收据只含计数、汇总和校验结论：[public-core-acceptance-v1.json](results/public-core-acceptance-v1.json)。截图不是声学回听或临床验证；本轮没有播放可听声音、连接手机或采集环境麦克风。

## 必要检查

新的合成 EDF/RML 测试实际走 EDF 解析、特征准备、官方摘要样式验收、工作台 API、参考裁剪、Range/波形、模型任务/参考保留、CSV 与删除；还检查坏 raw/划分/特征拒绝且不留孤立记录。此类夹具明确是 synthetic，不冒充真人或正式公开成绩。

新 RF 测试以微型十记录 synthetic corpus 真正训练和加载；权重/metrics/收据篡改时拒绝且不调用 joblib 反序列化。新实验登记测试覆盖默认不写、显式登记、路径/结构/非有限/冲突拒绝及坏登记隔离。

最终套件数量与新检出结果以同页 JSON 的 `checks` 为准；前端 typecheck/lint/build 实际通过。Windows 无符号链接权限造成的真实链接测试 skip 单列，模拟路径与恶意文件测试仍实际运行。Starlette 对 httpx TestClient 的弃用警告保留，未扩大依赖更新。

## 完成边界

公开数据主线有独立研究、软件、复现、说明与真实 Git 交付路径。SleepAccel 与 PSG-Audio 独立展示，不造同步时钟或同一受试者配对；历史模型、数据划分、指标和负面结果保持冻结。

Android 真机/锁屏/整夜、本人实际录音、跨设备泛化、跨种子研究与临床验证仍未验收。这些事实不被改写；可选本人采集没有成为主项目完成门槛。
