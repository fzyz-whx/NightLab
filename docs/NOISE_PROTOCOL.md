# 合成干扰与抗噪对照协议 v1

2026-10-25，真实抗噪性能计算前固定。本协议先核验混合/滤波，再运行模型对照；它不是已完成的性能结果。沿用PSG-Audio V3十人第二小时与原6/2/2受试者划分，无新增下载、室友录音或同意范围变更。

## 参考信号与合成干扰

原始Mic是已有背景与设备噪声的**观测录音**，不是无噪生理声真值。代码中的`clean`/`matched_clean`只指未额外注入合成干扰的参考分支；SNR衡量原始观测相对新增干扰，不是患者呼吸声相对全部环境噪声的绝对信噪比。

固定两类可控合成干扰：`white`为PCG64 float32标准高斯序列；`mains_hum`为50/100/150/200Hz正弦叠加，幅度1/0.5/0.25/0.125、四个固定随机相位。它们不代表真实宿舍声、谈话或鼾声，没有用合成数据冒充室友录音。

按SHA256(record_id,split,kind,seed42)得到独立种子；不同受试者/集合不复用同一随机流。每条完整1小时录音、每类噪声仅生成一条与原生48k样本网格一致的序列，四档SNR复用该序列比较强度。相邻10秒/5秒hop窗口共享重叠部分的相同样本，不逐窗重新抽噪声或改增益。

## SNR、削波与滤波控制

1. 目标新增干扰SNR固定为-5/0/5/10dB。以整段录音经16k分析FIR降采样后的RMS定义：`alpha = RMS(reference16k)/(RMS(noise16k)*10**(SNR/20))`。不根据事件标签、模型结果或每个窗口单独定强度；局部10秒SNR可不同。零能量参考/噪声的SNR未定义，必须报错而不是填0或伪造达标。
2. 16k分析使用明确Kaiser5 FIR，长度`2*10*q+1`、截止`1/q`，q=原生率/16000。分块核心按q对齐，两侧11q原生样本guard，裁掉内部guard；只有真正录音边界补零。小信号测试必须与整段float64 resample_poly结果一致。这只用于校准；模型仍按原窗口特征代码重采样，窗口边界与整录音分析的区别明确保留。
3. 传统滤波固定为80–4000Hz Butterworth带通，N=4（最终8阶、4个二阶节），原生率下sosfilt零初态，状态跨块/窗口传递，不在每个窗口重启。它是工程对照，不假定这一定保留所有目标声；不据测试调截止频率。因果相位/群延迟不事后按参考标签平移补偿。
4. 先测整段原参考、滤波参考、加噪和滤波加噪四分支未缩放峰值，统一`g=min(1,0.98/max(四峰值))`。四分支均乘同一g并转float32，不使用clip、不做逐窗峰值归一化。这样滤波过冲也受同一上界约束，且原始参考的音量变化有明确对照。
5. 四分支为`matched_clean`、`matched_filtered_clean`、`noisy`、`filtered_noisy`。另保留原未缩放录音的冻结基线。必须记录每条件g、alpha、四分支实际峰值/削波数，并从最终float32 noisy与matched_clean的残差重新测量全段16k SNR；误差门槛1e-4dB，不仅检查alpha代数公式。
6. 滤波影响优先看下游分类与事件结果。若计算原始观测参考的恢复误差，必须说明参考仍含天然噪声；不声称完成了无噪真值监督去噪或医学目标声恢复。

滤波实现依据：[SciPy sosfilt及状态](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfilt.html)、[Butterworth阶数与SOS](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.butter.html)、[resample_poly与边界](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample_poly.html)。以项目锁定SciPy1.18.1的实际代码和人工测试核对，网页版本不是本机执行证明。

## 模型对照与选择边界

计划比较冻结RF、冻结干净训练CNN，以及同结构/优化参数的噪声增强CNN。RF/CNN旧报告不重写，阈值仍0.5，连续事件完全沿用EVENT_PROTOCOL.md。

增强模型仅在原六名训练受试者的明确监督窗上增加副本：每个原窗口保留一次未缩放观测，再按稳定窗口hash从两类×四档条件选一次加噪副本，标签和身份逐项复制。各条件依然来自该录音的完整连续噪声与共同增益；记录八类实际样本数。验证只用原未缩放明确标签窗，与旧CNN相同Macro-F1选点；不根据本轮噪声测试曲线改架构、阈值、截止频率或SNR组合。测试受试者绝不进入增强训练。

测试对固定两人完整两小时的八个噪声条件运行四分支，使用相同窗口与参考。报告每个噪声/SNR/处理/模型的窗口Macro-F1、AP、事件P/R/F1、FP/hour、定位误差和与对应增益参考的差值，不只挑有利条件。整段所有719窗参与事件推理，明确标签mask仅用于窗口分类。以同增益参考区分音量、干扰和滤波影响；原未缩放基线与匹配增益基线也同时保留。
